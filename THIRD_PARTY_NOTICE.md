# Materiały osób trzecich

Kod aplikacji i autorskie elementy interfejsu nie przenoszą praw do materiałów należących do osób trzecich.

- Aplikacja nie publikuje reprodukcji okładek książek. Widoczne przy pozycjach grafiki typograficzne są autorskimi elementami interfejsu generowanymi z tytułu, autora i kategorii.
- Tytuły, nazwiska autorów, nazwy wydawnictw i znaki towarowe należą do odpowiednich autorów, wydawców lub innych uprawnionych podmiotów. Przy każdej książce aplikacja prowadzi do oficjalnej strony wydawcy.
- Dane bibliograficzne są zestawieniem informacyjnym. Krótkie opisy redakcyjne są tworzone na potrzeby kalendarza; automatyczne wykrywanie nie kopiuje pełnych opisów wydawców.
- Materiały osób trzecich nie są objęte żadną licencją udzielaną do kodu projektu.

Wniosek dotyczący korekty danych albo usunięcia materiału można zgłosić przez zgłoszenie w repozytorium GitHub.

## Third-party materials

The application does not publish reproductions of book covers. The typographic artwork shown with each title is an original interface element generated from the title, author, and category. Titles, author names, publisher names, and trademarks remain the property of their respective rights holders. Each listing links to an official publisher page. Third-party materials are not covered by any license granted for this project's source code. Correction and removal requests can be submitted through the GitHub repository's issue tracker.
